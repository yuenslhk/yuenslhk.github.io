Canon New F-1：機械與電子之間的專業旗艦

在 Canon 的單鏡反光機歷史上，New F-1 是一部承先啟後的機型。它是手動對焦 FD 系統的最後一部專業旗艦，亦是 Canon 在機械相機和電子相機之間取得最佳平衡的作品。它在1981年面世，陪伴無數新聞和體育攝影師走過整個八十年代。

一、F-1 的傳承

1971年，Canon 推出第一代 F-1，正式向 Nikon F 系列在專業市場的地位發起挑戰。F-1 以堅固耐用和系統完整見稱，其後在1976年推出改良版 F-1n。

到了八十年代初，電子化已成為大勢所趨，自動曝光逐漸普及。Canon 需要一部既保留專業機械可靠性，又能提供現代電子功能的新旗艦，New F-1 就在這個背景下誕生。

二、混合式快門：電池耗盡也能拍

New F-1 最受稱道的設計，是它的混合式快門。高速檔由機械控制，即使電池耗盡，仍然可以用這些速度繼續拍攝；慢速檔和自動曝光則由電子控制，提供更高的精度。

對專業攝影師來說，這個設計非常實際。在嚴寒的戶外、偏遠的地區或者長時間的採訪中，電池隨時可能失效，有了機械快門作後備，相機就不會因此「罷工」。快門簾採用鈦金屬薄片製造，耐用度和精度都達到專業要求。

三、模組化的系統設計

New F-1 的核心理念是「模組化」，攝影師可以按需要更換不同組件，把相機配置成最適合自己的工具。

可換觀景器：標準眼平觀景器提供手動曝光；換上 AE 觀景器後，相機便可進行光圈優先自動曝光。此外還有腰平觀景器和高倍率觀景器等選擇，適合微距、翻拍和特殊用途。

馬達與自動曝光：裝上 AE 電動捲片器或 AE 馬達後，相機便可以進行快門優先自動曝光，同時提供連續拍攝功能。換句話說，同一部 New F-1，可以按配件組合變成手動、光圈優先或快門優先相機。

可換對焦屏：New F-1 有多款對焦屏可供選擇。更特別的是，更換對焦屏亦會改變測光方式，攝影師可以按題材選擇平均測光、局部測光或點測光。這種把測光模式和對焦屏結合的設計，在同期相機中十分獨特。

四、為專業而生的耐用性

New F-1 的機身由金屬製造，結構堅固，能承受新聞、體育和野外攝影的嚴苛環境。Canon 在設計時特別重視可靠性，機身經過嚴格測試，在極端溫度和長時間使用下仍能穩定運作。

這部相機很快成為專業攝影師的主力器材，在新聞現場和大型體育賽事中經常可以見到它的身影。Canon 亦推出了洛杉磯奧運紀念版，突顯它在體育攝影界的地位。

五、FD 鏡頭系統

New F-1 採用 Canon FD 卡口，可以使用龐大的 FD 鏡頭群，由超廣角、標準以至超長焦鏡頭一應俱全。當中的 L 系列鏡頭採用螢石和特殊低色散鏡片，畫質出色，是新聞和體育攝影師的重要工具。完整的鏡頭和配件系統，令 New F-1 能夠應付幾乎所有拍攝需要。

六、FD 時代的終章

1987年，Canon 推出 EOS 自動對焦系統，改用全新的 EF 卡口，FD 系統逐步被取代。New F-1 一直生產至九十年代初，成為 FD 系統最後一部專業旗艦。Canon 其後的專業旗艦，例如 EOS-1，已全面進入自動對焦年代。

今天，New F-1 在二手市場仍然受到不少菲林愛好者和收藏家追捧。它堅固的機身、靈活的配置，以及機械快門帶來的安心感，令它在菲林攝影復興的年代再次發光。

七、結語

New F-1 是一部在時代交界處誕生的相機。它擁抱電子化帶來的便利，卻沒有放棄機械相機的可靠；它以模組化設計回應不同攝影師的需要，展現了 Canon 對專業市場的深刻理解。作為 FD 系統的最後旗艦，New F-1 不只是一部相機，更是 Canon 手動對焦時代的總結。
